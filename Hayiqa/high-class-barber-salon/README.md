# High Class Barber Salon

Owner folder: Hayiqa. Variants: Glossy and Ticket. Shared assets live in `assets/`.

## Why these templates

- **Glossy** matches the “High Class” name, monochrome storefront identity and combined barber/salon positioning with a premium editorial presentation.
- **Ticket** provides a meaningfully different booking-first option for a business where customers choose among multiple professionals on Booksy.
